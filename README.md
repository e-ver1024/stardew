# 星露谷物语 · 网页复刻版

继承爷爷留下的旧农场，开垦土地、播种浇水、钓鱼挖矿，在四季轮回中把荒地经营成属于你的星露谷。

纯前端单页应用，浏览器打开 `index.html` 即可运行——零依赖、零外部素材，全部画面由 Canvas 程序化绘制。

在线：https://e-ver1024.github.io/stardew/

## 特性

- **纯前端**：HTML + CSS + 原生 JavaScript，无框架、无构建工具
- **Canvas 程序化绘制**：地块、作物、角色、建筑、天气全部用代码绘制，无图片资源
- **零依赖**：本地双击 `index.html` 即可运行
- **WebAudio 合成音效**：所有音效用振荡器实时合成

## 项目结构

```
stardew/
├── index.html        # 主页面与 HUD/UI
├── css/style.css     # 星露谷风格样式
└── js/
    ├── data.js       # 静态数据：地块、作物、物品、工具、NPC、商店
    ├── draw.js       # Canvas 程序化绘制（地块/作物/角色/建筑/图标）
    ├── world.js      # 地图生成与地块、物件管理
    └── game.js       # 主循环、玩家、交互、时间系统、UI
```

## 核心玩法

- **种田**：锄头开垦 → 播种 → 浇水 → 收获 → 出货箱结算
- **资源采集**：斧头砍树、镐子敲石、镰刀割草、野外采集
- **钓鱼**：水边抛竿，按住空格/鼠标控制浮标跟着鱼
- **矿洞探险**：森林右上角矿洞，逐层下探，挖铜/铁/金/煤
- **时间系统**：四季轮回、昼夜光照、天气与雨天自动浇水
- **NPC 交互**：与刘易斯、莉亚、谢恩聊天

|------|------|

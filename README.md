# 星露谷物语 · 网页复刻版

继承爷爷留下的旧农场，开垦土地、播种浇水、钓鱼挖矿、狩猎烤肉，在四季轮回中把荒地经营成属于你的星露谷。

纯前端单页应用，浏览器打开 `index.html` 即可运行——零依赖、零外部素材，全部画面由 Canvas 程序化绘制。

在线：https://e-ver1024.github.io/stardew/

## 特性

- **纯前端**：HTML + CSS + 原生 JavaScript，无框架、无构建工具
- **Canvas 程序化绘制**：地块、作物、角色、建筑、天气、动物、怪物全部用代码绘制，无图片资源
- **零依赖**：本地双击 `index.html` 即可运行
- **WebAudio 合成音效**：所有音效用振荡器实时合成
- **视角缩放**：鼠标滚轮缩放（55% ~ 220%），平滑过渡

## 世界地图

96 × 78 的大地图（约为初版的 2.25 倍）：

- **农场**：围栏圈出的可耕种区域，可砍树开荒、布置火堆与工作台
- **鹈鹕镇**：皮埃尔杂货铺、诊所、酒吧、博物馆与民宅
- **东部森林与湖泊**：第二个钓鱼点，松林密布
- **南部河流**：蜿蜒横贯全图，三座木桥连通南北
- **矿洞**：森林右上角，逐层下探，每次进入布局随机

## 核心玩法

- **种田**：锄头开垦 → 播种 → 浇水 → 收获 → 出货箱结算；四季作物，换季枯萎，雨天自动浇水
- **资源采集**：斧头砍树、镐子敲石、镰刀割草、野外采集（四季共 35 种）
- **钓鱼**：水边抛竿，按住空格/鼠标控制浮标；四季专属鱼种，鱼获有普通/银/金/铱四档品质，完美判定直接给高品质
- **矿洞探险**：矿脉只存在于矿洞，随深度递进（铜→铁→金→铱），深层有稀有宝石矿脉；长按持续挖矿；**矿洞一片漆黑，记得插火把**
- **制作系统**：商店购买工作台（250 金）放置后打开制作面板
  - 火把（木材+树液）、栅栏、石墙、黑莓果酱、**火堆**（3 火把）
- **狩猎**：白天农场随机出没兔子、野鸡、青蛙——靠近会逃跑，追上点击捕获，掉落对应肉；**点击火堆可把生肉烤成熟食**（回体力 +75%、卖价翻倍）
- **夜晚怪物**：19:00 后围栏外出没史莱姆、蝙蝠、幽灵，点击攻击（持工具伤害更高），掉落粘液/蝙蝠翅膀/灵质；被碰到会扣体力，体力归零会被打晕
- **放置与拆除**：工作台/火堆/栅栏/石墙皆可放置；斧头可拆栅栏/火堆/工作台、镐子可拆石墙，均回收物品
- **昼夜氛围**：夜幕深沉（19 点后），光源只有火把与火堆——出门打怪前记得备足火把
- **时间系统**：四季轮回、天气（晴/雨/雪）、每天 6:00 开始、凌晨 2:00 强制昏倒
- **NPC 交互**：与刘易斯、莉亚、谢恩聊天

## 操作

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 鼠标左键 | 使用工具 / 攻击怪物 / 捕猎 / 放置物品 |
| 鼠标滚轮 | 缩放视角 |
| 空格 | 对面前格子使用 / 钓鱼 |
| E | 交互（门/床/出货箱/工作台/火堆/NPC） |
| 1~0 | 切换快捷栏 |
| Tab / I | 背包 |
| F | 食用 |
| H | 帮助 |
| Esc | 关闭面板 |

体力耗尽时吃采集物、鱼或烤肉可回复；被怪物打晕会被送回家并损失体力。

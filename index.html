📖 操作说明

基础操作

  • W A S D / 方向键　移动
  • 鼠标左键　对点到的格子使用当前物品
  • 空格　对角色面前的格子使用
  • E　交互（开门 / 睡觉 / 出货箱 / 和村民聊天）
  • 数字 1~0　切换快捷栏物品
  • Tab / I　打开背包　F　食用手中食物
  • H　帮助　Esc　关闭面板
  • 鼠标滚轮　缩放视角（55% ~ 220%，以鼠标为中心）

farming 流程

  • ① 选 锄头 点击草地 → 开垦出农田
  • ② 选 种子 点农田 → 播种（只能种当季作物）
  • ③ 选 洒水壶 点农田 → 浇水（水边点击补水）
  • ④ 成熟后 空手点击 收获，放到 出货箱 次日结算
  • 作物每天浇水才会生长，雨天自动浇水
  • 换季时非当季作物会枯萎，注意季节

其他玩法

  • 斧头 砍树 → 木材 / 树液
  • 镐子 敲石头 → 石头；矿洞里有铜/铁/金/煤
  • 镰刀 割杂草 → 纤维
  • 钓鱼竿 点水面 → 钓鱼小游戏（按住空格/鼠标控制浮标）
  • 矿洞 在森林右上角，梯子可下一层，出口梯子回到地面
  • 每天 6:00 开始，凌晨 2:00 前回家睡觉，否则会累倒
  • 体力耗尽无法干活，吃采集物或鱼可回复
  • 🌙 夜晚危险：19:00 后农场围栏外会出没史莱姆、蝙蝠、幽灵，点击怪物即可攻击（持工具伤害更高），掉落粘液 / 蝙蝠翅膀 / 灵质；被碰到会扣体力，体力归零会被打晕
  • 🛠️ 制作：皮埃尔商店购买工作台（250 金），手持它点击空地放置，再点击工作台打开制作面板；配方：火把 / 栅栏 / 石墙 / 黑莓果酱 / 火堆（3 火把）
  • 🔥 烤肉：放置火堆后点击它，把兔肉 / 野鸡肉 / 蛙腿烤成熟食（回体力更多、卖价更高）；火堆夜里会发光
  • 🐇 狩猎：白天农场会出没兔子、野鸡、青蛙，靠近会逃跑，追上点击捕获掉落兔肉 / 野鸡肉 / 蛙腿，按 F 食用恢复体力；18:00 后动物逐渐消失
